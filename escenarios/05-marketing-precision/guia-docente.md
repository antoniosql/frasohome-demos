# Guía rápida de uso docente

## Secuencia sugerida para la formación
1. **09 + 10** para construir la base de cliente y rentabilidad.
2. **11 + 12 + 13** para predicción, propensión y recomendación.
3. **14 + 15 + 16** para decisiones de promoción, devoluciones y activación local.
4. **17 + 18** para introducir IA generativa con guardrails y criterio de marketing.

## Cómo usarlos
- Los notebooks ya están ejecutados con outputs de ejemplo.
- Si el alumno quiere rehacer el caso, basta con ejecutarlos desde `escenarios/05-marketing-precision/notebooks`: localizan solos la carpeta `datos/`.
- Cada notebook exporta resultados a CSV para facilitar revisión, dashboard o corrección.

## Nivel docente
- **Avanzado pero guiado**: combinan explicación de negocio, código y outputs listos para discutir.
- **Enfoque marketing de precisión**: todos cierran con score, decisión, activación y KPI.

## Nota sobre GenAI
Los notebooks 17 y 18 no llaman a un LLM remoto. Preparan el contexto, los guardrails, los prompts y los borradores para que el uso posterior de GenAI sea controlado, auditable y útil desde negocio.
