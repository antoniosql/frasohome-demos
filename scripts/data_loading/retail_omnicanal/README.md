# Carga Retail Omnicanal

Utilidades auxiliares para cargar o ejecutar SQL sobre los datos retail.

## Archivos

- `carga-csv.py`: carga CSV.
- `run-sql.py`: ejecucion de scripts SQL por lotes.
- `csvee.py` y `csvee.ipynb`: utilidades exploratorias conservadas del material original.
